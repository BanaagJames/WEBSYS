About IT

The Bachelor of Science in Information Technology (BS IT) is a four-year program that trains students to become highly skilled in the practical and technical aspects of computer systems, networking, troubleshooting, and hardware repair.



The program offers three specialization tracks:

• Network and Security Track
• IT Automation Track
• Web and Mobile Application Development Track



The BSIT Web and Mobile Application Development Track supplements the programming courses students currently take. Additional programming languages, frameworks, tools, and software development best practices are introduced to strengthen real-world development skills.



Network and Security Track – focuses on basic to advanced networking and cybersecurity implementation. Students learn how to manage, secure, audit, and protect computer networks using industry-standard policies and procedures.



Web and Mobile App Development Track – enhances students’ programming knowledge through modern web and mobile technologies, frameworks, software tools, and application development practices.



IT Automation Track – focuses on integrating systems and software to become self-operating through the use of sensors, actuators, scripting, automation tools, and intelligent IT processes.
